# 低氧血症平台操作指南（使用者版）

适用版本：2026-10-10 更新的低氧工作流重构版；以管理员提供的实际部署版本为准。

这份指南从“打开网页”开始。平台由管理员提前安装并启动，您不需要输入安装命令，也不需要修改程序文件。“管理员”指负责安装和维护这套平台的人员。

当前功能用于离线研究：准备监护数据、训练模型、评测模型表现并下载结果。页面中的“低氧血症预测”是流程名称，目前不提供实时监护报警，也不用于临床诊断。

## 1. 使用前准备

请管理员交付时填写下表，您可以直接照着使用。

| 项目 | 管理员填写 |
| --- | --- |
| 平台访问网址 | ____________________ |
| 数据集名称，或提供给您的数据文件夹 | ____________________ |
| 本次任务：训练新模型 / 评测已有模型 | ____________________ |
| 应选择的模型名称 | ____________________ |
| 参数要求：使用默认值 / 按研究方案填写 | ____________________ |
| 遇到问题联系谁 | ____________________ |

在 Edge 或 Chrome 浏览器顶部的地址栏输入网址，按回车。平台装在自己电脑上、并使用本版默认配置时，网址通常是 `http://127.0.0.1:5174`。平台装在别的电脑上时，请使用管理员给您的网址。

网页打不开时先联系管理员。反复点击或重新上传数据不能解决网页未启动的问题。

## 2. 认识页面上的操作

| 页面位置或名称 | 用来做什么 |
| --- | --- |
| 下方聊天输入框 | 输入需求；按 Enter 发送，Shift + Enter 换行 |
| 对话中的选项卡片 | 点击想选的项目，也可以回复选项的完整名称 |
| 文件夹图标 | 选择数据文件夹；鼠标放上去显示“选择五通道数据目录” |
| 回形针图标 | 选择本机文件；鼠标放上去显示“选择本机数据文件” |
| 文件名旁的小叉号 | 发送前移除这次附带的文件 |
| 任务卡片 | 查看数据处理或训练状态，以及任务编号 |
| 任务卡片上的“停止” | 请求取消后台任务；确定不再需要本次任务时才点击 |
| 输入框旁的红色方块 | 停止当前对话接收，不能当成后台训练已取消的证明 |
| “下载评测 Excel” | 下载本次评测的表格文件 |

每次只操作当前最新的卡片，等平台回复后再做下一步。不要连续点击旧卡片，也不要把整段操作步骤一次性全部发送。

## 3. 开始并选择数据

在输入框发送：

> 开始低氧血症预测

页面会显示“选择低氧血症数据集类型”。按手头材料选择：

| 您拿到的材料 | 应选择 |
| --- | --- |
| 管理员已登记的数据集，或文件夹里有 `window_features.pkl` 和 `window_info.pkl` | 已处理数据 |
| 原始监护 CSV 数据、ZIP 压缩包，尚未生成上述文件 | 原始数据 |
| 不知道是哪一种 | 先请提供数据的人确认 |

“数据集”就是这次要分析的一批数据；“窗口”是从监护记录中截取的一小段时间数据。一个人可以对应多个窗口，窗口数量不等于患者人数。

### 3.1 已处理数据：优先从列表选择

点击“已处理数据”后，会出现“选择已处理数据”。如果列表中有管理员给出的数据集名称，直接点击它。随后应出现数据检查结果，以及“选择低氧血症后续操作”。

列表里没有您的数据时，可以使用下面的上传方法。

### 3.2 已处理数据：从自己电脑上传

1. 在“选择已处理数据”中点击“选择本机文件”。
2. 点击输入框左侧的**文件夹图标**，选择管理员提供的数据文件夹，然后确认。
3. 浏览器询问是否上传文件夹时，确认选对文件夹后继续。选择直接存放本批数据文件的文件夹，不要选包含多批数据的大目录。
4. 等待“正在上传...”提示消失，确认输入框上方出现“五通道窗口数据”或文件名称。
5. 点击发送按钮；也可以输入“检查这批数据”后发送。
6. 等待数据检查卡片。

如果浏览器不能选择文件夹，改点**回形针图标**。在弹出窗口中，按住 Ctrl 同时选中同一批数据的以下文件，再点击“打开”：

| 文件名称 | 是否需要 |
| --- | --- |
| `window_features.pkl` | 必须 |
| `window_info.pkl` | 必须 |
| `window_stats.json` | 有则一并选择，用于显示数据数量等统计 |

这几个文件应当一起上传，不要改名，不要混用不同批次的同名文件。窗口中的“打开”表示交给平台读取，您不需要自己打开文件查看内容。

如果平台提示“缺少统计文件”或“统计不可用”，联系管理员补齐后再开始训练。此时卡片中的 0 个窗口不一定表示数据为空。

### 3.3 只有管理员给出的数据位置

点击“输入路径或数据集 ID”，原样粘贴管理员给您的内容并发送。

“路径”就是文件或文件夹在电脑上的位置，这里必须是平台运行电脑能访问的位置。平台在另一台电脑上时，请通过上传传入自己电脑的数据，或请管理员提供可用位置。

### 3.4 原始数据：先处理，再继续

1. 点击“原始数据”。
2. 按提示粘贴管理员给出的原始数据位置。若还要求“ZIP 临时解压目录”，粘贴管理员提供的第二个位置；不知道时先联系管理员。
3. 在“原始数据处理参数”中，按研究方案选择“使用默认处理参数”或“修改处理参数”。
4. 确认平台显示的参数后，发送或点击 **“开始处理”**。
5. 等待任务卡片明确显示 **“已完成”**。
6. 点击 **“继续扫描数据集”**，等待数据检查结果。

ZIP 压缩包和原始目录的整理、存放位置，建议由管理员提前准备。不要用上一节专门选择五通道数据的按钮代替原始目录准备步骤。

“开始处理”只需提交一次。任务在“排队中”或“运行中”时不要反复提交；显示“失败”时，按第 8 节求助。

### 3.5 数据检查卡片看什么

确认“数据集名称/数据路径”对应本次数据，并核对以下信息：

| 卡片内容 | 您要确认的事情 |
| --- | --- |
| 窗口总数 | 与数据提供者给出的数量相符，且统计可用 |
| 低氧窗口数、非低氧窗口数 | 两类数据数量符合本次研究方案 |
| 窗口长度、预测间隔 | 与方案相符，不应自行猜测或修改 |

检查结果有疑问时先停在这一步。文件检查通过并不证明模型与数据一定匹配。

## 4. 选择训练还是评测

在“选择低氧血症后续操作”中选择：

| 选择 | 适用情况 | 下一步 |
| --- | --- | --- |
| 选择模型架构并训练 | 希望用本次数据训练一个模型 | 看第 5 节 |
| 选择已训练模型进行评测 | 已有保存好的模型，希望查看它在本次数据上的表现 | 看第 6 节 |

“训练”是让模型学习数据；“评测”是计算模型的表现。评测已有模型不需要重新训练。

## 5. 训练新模型

### 5.1 选模型和参数

1. 点击 **“选择模型架构并训练”**。
2. 在“选择模型架构”中点击管理员指定的名称，不要仅凭名称猜测哪一个更好。
3. 查看“当前模型架构详情”，按研究方案选择 **“使用当前架构参数”**，或由负责人指导修改。
4. 在“保存模型架构配置”中，需要以后复用这套设置，选 **“保存架构配置”**；只用于这次，选 **“本次使用，不保存架构配置”**。
5. 在“训练超参数”中，按方案选 **“使用默认训练超参数”** 或 **“修改训练超参数”**。
6. 修改时在编辑卡中填写负责人指定的值，点击 **“提交训练参数”**，再核对平台回复中的值。
7. 出现“训练配置已确定”后，核对数据、模型和参数，点击 **“开始训练”**。

如果没有参数要求，先与负责人确认能否使用默认设置。空白字段可能恢复默认值，并不代表关闭相应功能。

架构详情卡用于查看信息。保存架构配置只保存“准备怎样训练”，此时还没有训练好的模型。对新手而言，请先使用负责人指定的现有架构；“创建新的模型”中的文字设计也不一定能够直接训练。

### 5.2 等待训练完成

| 任务状态 | 您应当做什么 |
| --- | --- |
| 排队中 / 运行中 | 等待，不要再次点击“开始训练” |
| 已完成 | 进入下一步 |
| 失败 / 已取消 | 本次没有成功完成，按第 8 节处理 |

达到 100% 不一定成功，必须看状态文字。训练时间取决于数据大小、模型和电脑性能，没有统一的完成时间。

### 5.3 保存训练好的模型，再设置评测

1. 任务显示“已完成”后，点击任务卡中的 **“开始评测”**，或发送“开始评测”。此时先出现“保存训练模型”，并未立即计算评测。
2. 以后还要使用这个模型，点击 **“保存训练模型到模型空间”**，等待“训练模型已保存到模型空间”的提示。
3. 只做这一次评测，点击 **“仅本次评测，不保存训练模型”**。这表示不加入可复用模型列表，并不表示立即删除磁盘文件。
4. 出现“选择评测指标”后，按第 7 节继续。

请区分：**保存架构配置**保存设置；**保存训练模型**保存可再次选择的训练结果；**导出 Excel**下载评测表格。三者不能互相代替。

## 6. 使用已训练模型评测

1. 在数据检查后的卡片中点击 **“选择已训练模型进行评测”**。
2. 在“选择已训练模型”中点击管理员指定的模型名称。
3. 在“已训练模型操作”中点击 **“进入评测流程”**。
4. 按第 7 节选择指标和输出方式。

列表没有需要的模型时，联系管理员确认是否已训练并保存。保存过架构配置，不代表列表中已有训练好的模型。

请使用研究负责人确认与这批数据匹配的模型。目前平台不会自动识别所有不匹配情况，尤其不要自行混用不同通道、采样方式或窗口长度的模型与数据。

## 7. 运行评测并下载结果

1. 在“选择评测指标”中，通常选 **“全部指标（默认）”**；方案只要求某一项时，选对应指标。
2. 在“评测结果输出”中选 **“评测并导出 Excel”**，或 **“仅显示评测结果”**。
3. 提示“评测设置已保存”后，点击 **“开始评测”**。
4. 等待“评测完成”。期间不要重复提交；评测可能没有训练任务那样的进度条。
5. 如果选择了导出，点击 **“下载评测 Excel”**。浏览器询问保存位置时，选择便于找到的文件夹；否则通常可在浏览器“下载”列表找到文件。

### 7.1 如何看懂结果

当前网页主流程默认计算输入数据中**验证集**的指标，所以“本次评测数据”通常小于“输入数据集总窗口”。这本身不是数据丢失。不同患者/记录分组大小不同，验证窗口数量不一定恰好占固定百分比。

| 页面指标 | 简单含义 |
| --- | --- |
| AUC | 模型区分两类数据的能力，通常越高越好 |
| Recall（召回率） | 实际低氧窗口中被找出的比例 |
| Precision（精确率） | 被判断为低氧的窗口中，实际为低氧的比例 |
| F1 | 综合考虑精确率与召回率的指标 |
| Accuracy（准确率） | 全部评测窗口中判断正确的比例 |
| 验证集阈值 | 把模型分数转成分类结果的界限，与原始数据中的 SpO2 低氧阈值不同 |

指标应结合数据和研究方案，由研究负责人解释。验证集结果不等于独立测试集结论，单个高分也不代表可以用于实际诊疗。

结果卡只展示部分常用指标。其他指标未显示时，查看导出的表格；仍没有就联系管理员，不要把缺失值当成 0。

### 7.2 完成后保留什么

- 数据集名称、选择的模型名称、运行日期。
- 训练任务编号（任务卡中的 `task-...`），如果本次有训练。
- 需要复用时，保存成功提示中的模型编号（`model-...`）。
- 下载的 Excel，以及必要的参数和结果页面截图。

“评测完成”只代表计算结束。需要表格时另外确认文件已下载；需要下次再选模型时，确认已完成第 5.3 节的保存。

## 8. 遇到问题怎样处理

| 现象 | 您可以先做的事 |
| --- | --- |
| 网页打不开 | 确认网址，联系管理员检查平台是否已启动 |
| 上传后没有显示数据 | 等上传完成，检查是否一起选择了同一批配套文件，再发送 |
| 缺少文件、统计不可用或窗口数异常 | 截取数据检查卡，联系数据提供者，不要直接训练 |
| 找不到已训练模型 | 确认名称及是否曾保存，请管理员检查资源 |
| 任务失败 | 展开“查看最近日志”，把错误内容和任务编号发给管理员，不要连续重试 |
| 任务长时间没变化，或“进度刷新失败” | 记录状态和时间，联系管理员确认实际任务状态 |
| 模型产物不完整、数据不受信任、内存不足 | 保存错误信息交给管理员，换一种聊天说法通常不能解决 |
| 平台重启后，旧卡片不能继续 | 原步骤可能已丢失。先确认原任务是否仍在运行，再重新进入流程，避免重复训练 |
| 结果中的输入数据总数与所选数据不符 | 暂不使用结果，保留截图，请管理员核对来源 |
| 没有 Excel 下载链接 | 确认选了“评测并导出 Excel”；已选择仍没有时，保留结果卡并求助 |

求助时可以复制下面的模板：

```text
发生时间：
我选择的数据集和模型：
我刚刚点击或发送的内容：
页面出现的提示：
任务编号（如有）：
附：相关卡片截图或错误文字。
```

截图前遮住不需要提供的个人信息，问题描述中不需要发送原始患者数据。

## 9. 第一次操作的简短核对表

1. 使用管理员提供的网址、数据和模型名称。
2. 发送“开始低氧血症预测”，选数据，确认检查结果。
3. 按任务要求选择训练或评测。
4. 训练时等待“已完成”，再选择是否保存训练模型。
5. 选择指标和是否导出 Excel，再点击“开始评测”。
6. 核对结果、下载表格，记录数据和模型名称。

安装、环境配置和输出目录交给管理员处理，详见[部署与维护说明](hypoxemia-admin-guide.md)。
