# 低氧血症功能使用指南

这份指南给已经拿到单机版的普通使用者。安装、启动、数据存放位置和故障处理由管理员负责，您只需要按照页面提示完成低氧血症数据处理、模型训练或模型评测。

本功能用于离线研究：它可以检查数据、训练模型、评测模型并导出 Excel。它不提供实时报警，也不能用于临床诊断。

## 一、开始前准备

请向管理员确认以下内容：

- 单机版已经打开，网页可以正常进入。
- 本次使用的是哪一批数据。
- 是训练新模型，还是评测已有模型。
- 如果训练，管理员建议使用哪个模型和参数。
- 如果评测，管理员指定使用哪个已训练模型。

已处理数据通常包含以下文件：

| 文件 | 作用 |
| --- | --- |
| `window_features.pkl` | 每个时间窗口的五通道数据，必须有 |
| `window_info.pkl` | 每个窗口的标签和分组信息，必须有 |
| `window_stats.json` | 窗口数量、采样率和声明窗口长度，必须提供（或提供配套数据集清单） |

五个通道的顺序必须是：`SpO2、HR、PR、RR、PI`。不要把不同批次的同名文件混在一起，也不要自行修改文件名或内容。

## 二、页面上的常用操作

| 操作 | 用途 |
| --- | --- |
| 发送消息 | 按页面提示进入下一步 |
| 选项卡片 | 选择数据类型、模型、参数和输出方式 |
| 文件夹按钮 | 选择一批已处理数据文件 |
| 文件按钮 | 选择本机的几个配套文件 |
| 任务卡片 | 查看处理或训练状态 |
| 停止 | 请求取消正在运行的后台任务 |
| 下载评测 Excel | 保存评测结果表格 |

每次只操作最新出现的卡片。任务显示“排队中”或“运行中”时不要重复点击提交。

## 三、选择数据

在输入框发送：

> 开始低氧血症预测

选择数据类型：

- **已处理数据**：手上已有 `window_features.pkl` 和 `window_info.pkl`。
- **原始数据**：手上只有原始监护 CSV 或 ZIP，需要先由平台处理成窗口数据。

### 已处理数据

优先点击管理员登记的数据集名称。如果列表中没有：

1. 点击“选择本机文件”或文件夹按钮。
2. 选择同一批数据中的 `window_features.pkl`、`window_info.pkl`，以及配套的 `window_stats.json` 和数据集清单（如有）。
3. 等待上传完成。
4. 点击发送，等待“数据检查”结果。

检查结果中重点确认数据集名称、窗口总数、低氧窗口数、非低氧窗口数、窗口长度和采样率。发现数量或来源不对时先停止，不要直接训练。

### 原始数据

1. 点击“原始数据”。
2. 按页面提示选择原始 CSV 或 ZIP。
3. 使用默认处理参数，或按研究负责人给出的方案修改参数。
4. 点击“开始处理”。
5. 等待任务明确显示“已完成”。
6. 点击“继续扫描数据集”，确认窗口数据检查结果。

## 四、训练新模型

在后续操作中选择“选择模型架构并训练”。

1. 选择管理员指定的模型架构。
2. 查看模型架构详情。
3. 没有特别要求时，使用当前架构参数和默认训练超参数。
4. 如果需要以后再次使用这套设置，选择“保存架构配置”。这只保存配置，不代表已经有训练好的模型。
5. 核对数据集、模型和参数后，点击“开始训练”。
6. 等待任务显示“已完成”。

训练状态的含义：

| 状态 | 操作 |
| --- | --- |
| 排队中、运行中 | 等待，不要重复提交 |
| 已完成 | 进入保存或评测步骤 |
| 失败、已取消 | 记录任务编号和错误提示，联系管理员 |

训练完成后点击“开始评测”：

- 要以后从模型列表中再次使用，选择“保存训练模型到模型空间”。
- 只想查看这一次结果，选择“仅本次评测，不保存训练模型”。

“保存架构配置”和“保存训练模型”是两件不同的事。

## 五、评测已有模型

在数据检查完成后选择“选择已训练模型进行评测”：

1. 选择管理员指定的已训练模型。
2. 点击“进入评测流程”。
3. 选择评测指标，通常选择“全部指标”。
4. 选择“评测并导出 Excel”或“仅显示评测结果”。
5. 点击“开始评测”。
6. 等待“评测完成”。选择导出时，再点击“下载评测 Excel”。

模型和数据必须匹配。系统会检查五通道顺序、采样率、窗口长度和实际窗口长度；出现“不兼容”时不要继续尝试绕过检查，应联系管理员确认模型和数据来源。

页面默认展示验证集结果。验证集窗口数可能小于输入数据总窗口数，这是数据划分造成的，不代表文件丢失。

常见指标：

| 指标 | 含义 |
| --- | --- |
| AUC | 区分低氧和非低氧窗口的能力 |
| Recall | 实际低氧窗口被找出的比例 |
| Precision | 判断为低氧的窗口中实际低氧的比例 |
| F1 | 综合 Precision 和 Recall |
| Accuracy | 判断正确的窗口比例 |

指标需要结合研究方案解释，不能把单次结果当作临床结论。

## 六、完整使用示例

下面是一条从已处理数据到 Excel 的完整流程。假设管理员给你的数据集叫“夜间监护窗口-01”，并要求训练一个 `SegRNN` 模型。

1. 打开管理员提供的单机版网页。
2. 发送“开始低氧血症预测”。
3. 选择“已处理数据”。
4. 点击“夜间监护窗口-01”。
5. 检查卡片显示五通道顺序为 `SpO2、HR、PR、RR、PI`，窗口长度、采样率和窗口数量符合研究方案。
6. 选择“选择模型架构并训练”。
7. 选择 `SegRNN`，使用管理员指定的参数，点击“开始训练”。
8. 等待任务从“运行中”变为“已完成”。
9. 点击“开始评测”，选择“保存训练模型到模型空间”。
10. 选择“全部指标”和“评测并导出 Excel”。
11. 点击“开始评测”，等待“评测完成”。
12. 点击“下载评测 Excel”，保存文件。
13. 记录数据集名称、模型名称、任务编号、模型编号和 Excel 文件位置。

下次使用同一个训练模型时，重新从第 1 步开始，在第 5 步后选择“选择已训练模型进行评测”，直接选择保存过的模型，不需要重新训练。

## 七、向管理员求助时提供的信息

请提供：

- 使用时间；
- 数据集名称和模型名称；
- 刚刚点击的操作；
- 页面完整提示；
- 任务编号（如果有）；
- 错误卡片截图。

不要通过聊天发送原始患者数据。截图前遮住不需要的个人信息。
